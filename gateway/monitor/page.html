Fault guide

Every fault you can stage, what it means, and how a support person would track it down. Each one is something that really goes wrong on lab and device interfaces. Message problems go through the real gateway code; network problems are simulated, because nothing real can be disconnected here.

About this page

The feed starts with the project's example registrations, then a slice of the Synthea-generated feed the project tests at scale: each patient's registration followed by some of their lab reports, as a lab would send them.

The same code runs as a real listener on your own computer: python -m gateway listen waits on this computer only (port 2575, HL7's registered port), and python -m gateway send sends files to it and prints each acknowledgement. See the README.
