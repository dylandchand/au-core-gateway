Message Inspector

See a lab message become an AU Core record

Pick an example or paste an HL7 v2 message. The gateway's own code runs here in your browser: it splits the message into fields, translates it into Australia's FHIR standard and runs its own checks. Point at any part of either side to see where it came from.

Stays in your browserNothing you paste is uploaded. The page only downloads the gateway's code and Python itself.
Synthetic data onlyNever paste real patient information. Every example here is made up.
The official check runs elsewhereHL7's validator can't run in a browser. For the built-in examples, you see what it found in the project's automated tests.
